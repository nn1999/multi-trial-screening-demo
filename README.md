# 多临床试验入组预筛选 Demo
独立的 GitHub Pages 静态演示。默认载入两张用户授权展示的示例病历及其本地识别结果。

- 患者与医生双端联动；新增患者任务卡；ECI830 I期、II期及SPR1020标准卡片。
- 逐条展示当前材料、判断理由及证据缺口；可发起通俗补充问答。
- 新上传的补充图片在访问者浏览器内识别，不发送至识别服务器；首次使用加载Tesseract.js及语言模型。
- 补充资料和对话仅保存在当前浏览器，不会跨设备共享。点击重新开始可恢复内置病例。
- 此为本例规则演示，不是通用临床判定系统；正式资格由研究团队决定。

本地原项目保留；发布不包含工作日志、测试截图或其他病历。
